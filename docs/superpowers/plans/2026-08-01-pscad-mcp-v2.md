# PSCAD MCP v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use inline execution in this session, task-by-task with verification checkpoints.

**Goal:** Repair the PSCAD MCP foundation and core tools so they match the current `mhi-pscad`/`mhi-psout` APIs and can be registered with Codex over stdio.

**Architecture:** Add a small adapter and path-policy layer between MCP tools and MHI packages. Keep the existing tool modules and docs, but move version-sensitive calls and serialization into the adapter. Use unit tests with lightweight fakes for contracts and one installed `mhi.psout` sample for a parser smoke test.

**Tech Stack:** Python 3.12, FastMCP 1.x, `mhi-pscad` 3.1.x, `mhi-psout` 1.3.x, `unittest`.
