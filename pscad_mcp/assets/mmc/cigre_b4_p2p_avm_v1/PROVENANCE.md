# CIGRE B4-derived MMC AVM provenance

Public source: the approved design document and public CIGRE B4 context. This
repository-authored companion asset is an independent average-value model
contract. The fixed nominal values are an engineering derivation for the
Stage A acceptance case: 640 kV pole-to-pole and approximately 1000 MW. They
are not a reproduction of restricted CIGRE project files. The phrase original derivation identifies values created for this repository.

The arm-current decomposition and stored-energy equations are transcribed from
the approved design document and are labeled as original engineering
derivations for this asset. The equivalent conduction and switching-loss
coefficients are versioned AVM assumptions and must be reviewed with the
reference output before licensed acceptance.

The companion library contains only hierarchy, equations, and dimensioned
signal interfaces. It does not contain a complete station or two-terminal
link, customer project, author-machine path, or copied proprietary library.

The AVM limitations are explicit: individual submodule balance, semiconductor
switching stress and switching harmonics are not modeled. The half-bridge
blocked state retains a system-level diode-equivalent conduction path and
therefore declares `intrinsic_dc_fault_blocking=false`; it does not claim
device-level fault stress fidelity.
Golden waveforms are not generated by the builder; an independently assembled
and reviewed reference output is required before publication.
